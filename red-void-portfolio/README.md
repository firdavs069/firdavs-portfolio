# RED VOID — Firdavs Bakiyev Portfolio

A multi-page HTML/CSS/JavaScript portfolio starter.

## Pages
- `index.html` — Home
- `about.html` — About
- `projects.html` — Projects
- `skills.html` — Skills
- `contact.html` — Contact

## Run
Open `index.html` in a browser, or run a local server from this folder:
`python3 -m http.server 5500`

Then visit `http://localhost:5500`.

## Customize
- Replace text and project details with confirmed information.
- Add real project URLs and screenshots.
- Add an email address if you want one shown.
- The supplied portrait is in `assets/firdavs-portrait.png`.
